Source audit: 2026-10-26; native/backend follow-up against checkout 6e99acd. This is a release inventory, not a statement that App Store Connect or the live privacy policy has been updated. Reconcile against the exact deployed backend and final binary before submission. Apple's [App privacy details guidance](https://developer.apple.com/app-store/app-privacy-details/) requires assessment of data sent off-device and retained, including partners; local-only data is a different case.

## Confirmed follow-up findings (2026-10-26)

- **AI answer checking:** submitted guess and expected answer can enter the semantic-validation model prompt through Vercel AI Gateway. Configured fast-tier fallbacks include Google, OpenAI and xAI; this does not mean every request reaches each provider. References: `apps/web/src/app/api/puzzles/guess/route.ts:194`, `apps/web/src/ai/services/answer-validation.ts:124`, `apps/web/src/ai/client.ts:162`, `apps/web/src/ai/config.ts:33`. Final processor disclosures must include actual deployed routing and provider retention.
- **Eve replies:** native `APIClient.streamQuip` sends guess, puzzle ID and score tier to `/api/puzzles/quip`. The constructed prompt includes the guess, puzzle type and tier through Gateway fast-tier streaming, currently Google as primary. Account ID/email are not intentionally added to that prompt, but typed guess content may contain personal data. References: `apps/ios/Rebuzzle/Services/APIClient.swift:49`, `apps/web/src/app/api/puzzles/quip/route.ts:134`, `apps/web/src/ai/client.ts:261`. Provider settings and retention remain unverified.
- **Achievement emails:** registered-player achievement unlocks can send email address, username and achievement/progress details through Resend when configured. References: guess route line 398 and `apps/web/src/lib/notifications/email-service.ts:67,274`. Do not describe native-triggered server processing as purely on-device.
- **Timezone:** native request timezone persists in `userStats.streakTimeZone`; references `apps/ios/Rebuzzle/Services/APIClient.swift:28` and `apps/web/src/lib/auth.ts:263,355`.
- **Guest identification:** guest records retain IP-derived hashes, device ID and last-seen metadata. Rate limiting separately uses raw IP in an in-memory key; rate-limit expiry is not a retention policy for other stores. References lazy guest route line 79 and rate-limit middleware line 114.
- **Analytics:** account-linked login/return events are stored in MongoDB analyticsEvents. Fast successful solves retain difficulty-calibration feedback identifiers containing puzzle ID and user ID, duration, attempt count and hints. References login route line 60, `apps/web/src/db/analytics-ops.ts:18`, and `apps/web/src/ai/learning/learning-loop.ts:25`.
- **Deletion:** the account deletion transaction explicitly removes user-linked calibration feedback IDs, analytics events and stats (`apps/web/src/app/api/user/account/route.ts:35,54`). This is source evidence; no claim is made about external processor logs or backups.

- **Retention conflict:** `apps/web/src/db/indexes.ts:295` configures a 90-day analytics TTL; the earlier setup script leaves a TTL commented out (`apps/web/scripts/setup-mongodb.ts:173`), and normal production startup does not automatically initialize indexes (`apps/web/src/db/mongodb.ts:72`). Neither the old policy's one-year duration nor a replacement 90-day promise is verified without reading live indexes. Attempts, account records and learning pulses have no TTL established by this audit.
- **Website email defaults:** signup creates or updates `emailSubscriptions.enabled:true` (`apps/web/src/app/api/auth/signup/route.ts:196`). Website Settings includes `EmailNotificationForm`; notification email unsubscribe links disable the subscription. These controls do not establish that achievement emails are suppressed; the native solve-triggered achievement path has no preference check. Do not describe automatic subscription as affirmative opt-in.
- **Deletion limits:** deletion covers the application collections enumerated by the route, removes account-scoped local files and clears the auth token. Published puzzle content may remain without attribution; the native Keychain installation device ID remains. Apple records, external AI/email/hosting logs and backups are not erased by this application transaction.
- **Security claims:** source supports HTTPS app requests, bcrypt password hashing and Keychain storage. A recurring security-assessment practice was not established; do not claim one without operational evidence.

Still unresolved: production hosting log retention; database backups/retention; enabled email delivery and its retention; AI Gateway and downstream provider routing/logging/retention; Apple reporting; final archive privacy report. No final store privacy answers or revised public policy were published from this inventory. Do not treat this document or the corrected policy source as approval to publish unverified privacy declarations.
