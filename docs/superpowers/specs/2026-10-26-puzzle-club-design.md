# Rebuzzle: the daily puzzle club

Native redesign, authorized for implementation without selection checkpoints. Keep the real daily game, APIs, progress math and TestFlight identity.

## Direction
A crafted puzzle publication with a tactile game board: oversized rounded display type, an ink/cream palette, restrained electric blue for active play and gold for earned rewards. Thorbis supplies native tab/stack navigation, quiet chrome, solid surfaces, inset fields, rimmed controls and 44pt targets. Rebuzzle supplies personality through language, typographic composition, attempt tokens and a satisfying confirmed solve. No decorative marks inside the clue that could be mistaken for puzzle data.

Play leads with “Make it click.”, a daily/date masthead and actual difficulty. A focused stage contains the exact existing puzzle, with a compact label outside the clue. Three attempt tokens show the real state. Eve retains the complete AI conversation. Input, hide-keyboard action, hint disclosure and error recovery remain available. Earned solve state gets an oversized “Aha!” and real XP/star outcome. Revealed answers never receive a false win.

Journey becomes a visible three-stop weekly trail with completed/current/locked status derived from existing completed days, an earned level identity and a compact collection of the four real badges. Avoid invented currencies, arbitrary countdowns, fake peers or punitive reminders. Existing reminders remain opt-in.

## Accessibility and compatibility
Support light/dark, Dynamic Type including XXXL, reduced motion, VoiceOver, iPhone/iPad. Preserve layout of all actual clues, word matching, local drafts, identifiers and server reconciliation. No gameplay API or published puzzle changes. Tests exercise existing win/loss/keyboard flows. Simulator screenshots inspect ready, wrong, win, Journey, large text and dark mode.
