# AI puzzle craft

The user wants substantially better AI puzzle generation, building on the daily challenge policy. Improve the actual invention of clever, fair, original visual mechanisms; do not substitute higher scores or weaker acceptance gates for quality.

The current answer-first path freezes a deterministic ingredient arrangement before the model runs. A bounded mechanism designer should be able to arrange and transform supported text/catalog clues for the fixed answer, explain the linked deductions, identify a tempting alternative reading and its disambiguating visible cue, and propose three progressive hints. The host validates the plan and composes the authoritative board. Later tool-loop output cannot silently change that approved structure. Existing novelty, catalog provenance, blind screenshot recognition, independent solving and editorial reasoning gates remain mandatory.

Critique must receive actual layout, text emphasis and positions rather than only flattened words. Repairs may revise an approved mechanism once under the existing bounded repair budget while keeping the intended answer and re-running qualification. Hints should orient attention, then explain the relationship, then scaffold the key deduction, without leaking the complete answer or repeating the same information.

Use the existing TypeScript/Vercel AI SDK pipeline; no new provider SDK. Separate the expensive daily creative work from cheap gameplay feedback. Preserve existing published dates. Cap added planning calls and retain failure diagnostics. A small live pilot is diagnostic evidence, not statistical proof of improvement or hours-long difficulty. Never publish benchmark candidates as daily puzzles.

## Live-trial refinement

A target-8 trial returned HISTORY, a book, REPEAT, HISTORY, ITSELF and was correctly rejected as difficulty 4. Exact seed text requirements were forcing literal explanations onto the board. For the new mechanism path, seed cues therefore become inspiration. The answer remains fixed, every actual asset must resolve to the reviewed catalog, the approved board remains immutable, and independent publication gates remain mandatory. Legacy preflight generation retains its exact ingredient contract. This changes creative freedom, not the difficulty threshold.

Early deterministic score/difficulty failures may influence a short-lived, planner-versioned seed/technique preference. Provider or missing-evidence failures must not be interpreted as puzzle quality. This preference never changes acceptance gates and retains exhausted alternatives.

Reviewed catalog SVGs must pass pixel integrity and independent player-size recognition; generated-icon shape-count heuristics are not a substitute for recognizing intentionally simple reviewed icons.
